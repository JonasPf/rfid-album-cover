Upload and crop

Add any image and choose which square part of it appears in the art area.

Upload

  • The user picks a file, or drops it on the upload zone. Several files can be added at once.
  • JPEG, PNG and WebP are accepted.
  • The crop dialog opens for each file in turn. Confirming adds a card entry with an empty artist and title, then puts focus in its title field. Cancelling skips that file and moves on to the next.

Crop dialog

The same dialog re-crops an existing card entry. See Card list.

  • A square frame shows exactly what the art area will show.
  • Pan: drag the image with a mouse or by touch, or press the arrow keys while the frame has focus. Each key press moves the region by 5 % of its side.
  • Zoom: use the slider or the mouse wheel. The slider zooms around the frame centre, the wheel around the pointer. The minimum zoom makes the image just cover the frame. The maximum is 8× the minimum.
  • The image always covers the frame completely, so no empty area can show.
  • A new image starts at minimum zoom, centred.
  • The crop is stored as a square region in source-image pixels, rounded to whole pixels.

Acceptance criteria

IDCriterion
AC-UPLOAD-1Choosing a JPEG, PNG or WebP file through the file picker opens the crop dialog for it.
AC-UPLOAD-2Dropping a supported file on the upload zone opens the crop dialog for it.
AC-UPLOAD-3An unsupported or unreadable file shows "<file name> is not a supported image (JPEG, PNG, WebP)" and adds nothing.
AC-UPLOAD-4Adding 3 files opens the crop dialog 3 times in sequence. Each confirmation adds one card entry.
AC-UPLOAD-5Confirming adds a card entry with an empty artist and title, and focuses its title field.
AC-UPLOAD-6Cancelling (button or Esc) adds nothing. With several files, the dialog moves on to the next file. For a re-crop, it leaves the entry unchanged.
AC-CROP-1For a 1600 × 900 px image, the initial crop is the centred 900 × 900 px square.
AC-CROP-2Dragging, or pressing an arrow key with the frame focused, moves the visible region. The crop never extends past the image edges.
AC-CROP-3Zoom is limited to between the minimum (image covers the frame) and 8× the minimum.
AC-CROP-4After confirming, the card preview's art area shows the same region as the frame did.
