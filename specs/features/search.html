Search

Find albums in the iTunes catalogue and add them as card entries, with cover art, artist and title filled in.

Behaviour

  • The user types a search term and presses Enter or the Search button.
  • The page sends the request below and shows up to 25 results. Each result shows a thumbnail, the artist and the album title.
  • Clicking a result adds a card entry to the end of the card list. The result stays in the list, so the same album can be added again.
  • The card entry uses the 1200 × 1200 px artwork. The crop starts as the full square image.

Request

GET https://itunes.apple.com/search?term=<term>&media=music&entity=album&country=US&limit=25
Response fieldUsed as
artistNameArtist
collectionNameTitle
artworkUrl100Thumbnail. Replacing 100x100bb with 1200x1200bb gives the full-size art.

Acceptance criteria

IDCriterion
AC-SEARCH-1Submitting a term (by Enter or the button) sends one request with the parameters above, with the term URL-encoded.
AC-SEARCH-2Each result shows its thumbnail, artist and album title, in API order.
AC-SEARCH-3Clicking a result appends a card entry whose artist and title equal artistName and collectionName and whose image comes from the 1200 px artwork URL.
AC-SEARCH-4Clicking the same result twice adds two card entries.
AC-SEARCH-5Zero results show "No albums found".
AC-SEARCH-6A network or HTTP error shows "Search failed. Check your connection and try again." Existing card entries are unaffected.
AC-SEARCH-7If the artwork fails to load after a click, no card entry is added and "Could not load cover art" is shown.
AC-SEARCH-8An empty or whitespace-only term sends no request.
