ADR 0001: Static, client-only app

Status: accepted · 2026-10-14

Context

The tool searches album art, crops images and builds a PDF. It holds no secrets and needs no shared state. The iTunes Search API and Apple's artwork server both send Access-Control-Allow-Origin: *, so a browser can call them directly and draw the artwork into a canvas.

Decision

Build a static single-page app with no backend, hosted on GitHub Pages. All image processing and PDF generation run in the browser.

Alternatives

  • Go web server (the default stack): adds hosting and operations work for no functional gain.
  • CLI: no visual crop, and harder to check the result before printing.

Consequences

  • Free hosting with no server to maintain.
  • If Apple drops CORS on either host, search breaks with no proxy to fall back on. Upload keeps working.
  • The build must work under the Pages sub-path, so all asset URLs are relative.
