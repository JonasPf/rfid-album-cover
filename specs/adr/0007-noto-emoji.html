ADR 0007: Bundled Noto Emoji

Status: accepted · 2026-10-19

Context

An emoji must print as sharply as album art: a 51 mm art area at 300 dpi needs about 600 px. System emoji fonts differ by operating system and browser. Apple Color Emoji on macOS is a set of bitmaps of at most 160 px, about 80 dpi on a sticker. To be searchable, the picker also needs each emoji's name, keywords and category.

ADR 0001 and ADR 0003 keep the page free of third-party requests other than Apple's.

Decision

  • Ship the Noto Emoji SVGs (Apache 2.0, from the @iconify-json/noto package) with the app: one file per emoji, at emoji/<code points>.svg.
  • Ship an index, emoji/index.json, with each emoji's English name, keywords, category and order from Emojibase (emojibase-data, MIT). Only emoji that both sources have are included.
  • A Vite plugin builds both from the packages: it writes them into dist/ on build and serves them from memory in the dev server. Nothing generated is committed.
  • The page loads the index when the Emoji tab first opens, and each SVG when it scrolls into view or is picked. A picked SVG is drawn on a canvas at 1200 × 1200 px.

Alternatives

  • System emoji font on a canvas: no dependency, but blurry on macOS, and the look depends on the system.
  • Twemoji: vector graphics, but the set stops at Unicode 15.0 (2022), and the CC BY 4.0 licence needs a credit in the app.
  • Fluent Emoji: vector and MIT-licensed, but its flat style matches neither Apple's nor Google's emoji, which users know best.
  • SVGs from a CDN: keeps the site small, but every pick tells a third party what the user chose.
  • All graphics in one file: one request, but about 24 MB before the first emoji shows.

Consequences

  • dist/ grows by about 3,700 files and 24 MB. A visit downloads only the emoji it shows; the index is about 55 kB compressed.
  • Country flags are not available: the Noto package has none.
  • Emoji newer than the Noto package are missing until the dependency is updated.
  • dist/emoji/LICENSE.txt carries the Apache 2.0 and MIT licence texts, and the README credits both sources.
