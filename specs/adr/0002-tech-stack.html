ADR 0002: Tech stack

Status: accepted · 2026-10-14

Context

The preferred default stack is Go, Taskfile, SQLite or Postgres, Docker and Playwright. ADR 0001 rules out a server, so Go, the database and Docker have no role.

Decision

ConcernChoice
LanguageTypeScript (strict)
Build and dev serverVite
UISvelte
PDFpdf-lib, with fontkit for embedding the font
FontOne open-licence sans-serif with regular and bold weights (e.g. Inter), bundled with the app and used for both preview and PDF
Unit testsVitest
E2E testsPlaywright (Chromium, Firefox, WebKit)
Lint and formatESLint, Prettier, svelte-check
Task runnerTaskfile
CI and hostingGitHub Actions, GitHub Pages

Alternatives

  • Go compiled to WebAssembly: keeps Go, but gives a large bundle and awkward DOM and canvas interop.
  • Plain JS with no build step: no type checking, and thin lint and build tasks.
  • React or Preact: works, but needs more boilerplate than Svelte for this small UI. Svelte also has built-in transitions for the sliding list animations.

Consequences

  • Node.js is a dev dependency only. Users get static files.
  • Taskfile and Playwright from the default stack stay, so the developer workflow commands are unchanged.
