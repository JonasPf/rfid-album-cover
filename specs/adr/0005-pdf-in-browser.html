ADR 0005: PDF generated in the browser

Status: accepted · 2026-10-14

Context

Stickers must print at exact physical size. Browser print dialogs scale and add margins differently in each browser.

Decision

Build the PDF in the browser with pdf-lib, at exact A4 dimensions. Print the 100 mm calibration line on each page so the user can check the scale.

Alternatives

  • CSS print layout with Ctrl+P: no dependency, but the scale and margins depend on the browser and the user's dialog settings.

Consequences

  • The output is identical across browsers. The user still has to choose "Actual size" in the PDF viewer.
  • Text layout must be computed in code, using the embedded font's metrics, and shared with the preview so the two always match.
