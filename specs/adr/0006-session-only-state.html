ADR 0006: Session-only state

Status: accepted · 2026-10-14

Context

The typical use is to collect a few albums, print one sheet, and be done.

Decision

Keep the card list and the inset in memory only. Nothing is stored in the browser or exported.

Alternatives

  • IndexedDB autosave: survives reloads, but needs storage quota handling and a "clear" action.
  • Export/import a collection file: needs a file format to maintain.

Consequences

  • A reload loses the work, so the page asks for confirmation before unloading while the list is not empty.
  • Reprinting a card means searching or uploading it again.
